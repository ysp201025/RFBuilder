How this works: a browser can't run the Java/Android SDK/Gradle toolchain itself, so a genuine .apk can't be compiled inside this static page. Instead, RFBuilder does two real things: (1) it packages your project into a real, buildable Android Studio (WebView) project you can compile into a real signed APK with one command, and (2) it plays out the build pipeline below so you can see each stage a real build server would run. Use the pipeline to preview the process, then export the real project to actually ship it.
